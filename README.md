# Online Marketing Linktjekker

Linktjekkeren is a free website analysis tool developed by Online Marketing for examining link structures, outbound linking patterns and technical signals that may be relevant when evaluating websites used for link building.

The tool is freely available to use online. The source code is proprietary and is not distributed through this repository.

Online Marketing was established in Denmark in 1995 and has worked professionally with search engine optimization since 1999.

## Linktjekkeren

Linktjekkeren is designed to provide a structured technical examination of a website and its linking environment.

Rather than relying solely on third-party SEO metrics, the tool examines observable characteristics of the website itself.

The analysis can include signals related to:

- Internal link structures
- Outbound links
- Repeated linking patterns
- Commercial and editorial destinations
- Sponsored content signals
- Link attributes
- HTTP status codes
- Canonical URLs
- Sitemap information
- Website structure
- Directory and hub-like linking patterns

The purpose is to provide additional technical information that can be used when evaluating websites and links.

## Sample-based analysis

Linktjekkeren uses a limited sample of pages rather than attempting to crawl an entire website.

This approach is intentional.

The objective is to identify recurring structures and observable link patterns while reducing unnecessary requests to the analyzed website.

A sample-based analysis should therefore be interpreted as an indication of the structures found within the examined pages and not as a complete mapping of every page or link on the domain.

## Link patterns and structure

A large number of different destination domains does not necessarily mean that a website has a naturally diverse link structure.

Linktjekkeren therefore examines both destination diversity and structural patterns across the sampled pages.

Recurring outbound link structures, commercial destinations and hub-like patterns may provide additional context when evaluating a website used for link building.

## Technical observations

The results produced by Linktjekkeren are technical observations based on the pages and signals available during the analysis.

The tool does not automatically classify a website as:

- a link farm
- a private blog network (PBN)
- spam
- a low-quality website

Such assessments require broader evaluation and professional judgement.

Individual signals should therefore not be interpreted in isolation.
